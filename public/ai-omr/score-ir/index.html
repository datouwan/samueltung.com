Architecture update · August 2026

The renderer can do it.
The Score IR cannot — yet.

Verovio and MusicXML already support the rich notation needed for violin practice: chords and double stops, beam groups, fingerings, ties, slurs, articulations, bowing marks, tuplets, dynamics, and multiple voices. The next semantic bottleneck is our internal score representation.

𝄞 ♪ ♯
Keep Verovio.

Upgrade the contract between AI output and MusicXML. The model should produce compact musical structure, not raw XML.

Current state

What V1 can and cannot express

The current representation is intentionally monophonic and was the right choice for proving the first recognition loop.

Already supported

Pitch, duration, rests, key signature, time signature, dotted values, accidentals as pitch alteration, and ties.

Chord / double stop

Not supported. The current MusicXML parser explicitly rejects chord notes.

Beam relationships

Not represented. Duration exists, but beam membership, level, and hooks are lost.

Fingering & engraving

No per-note fingering and no separate representation of an explicitly printed accidental.

Target architecture

Introduce a semantic Score IR

The AI recognizes structure; deterministic code validates it and writes standards-compliant MusicXML; Verovio handles engraving.

First rich-notation milestone

Support the violin example first

A beamed dotted-eighth + sixteenth pattern with double stops, stacked fingerings, and a printed sharp is a useful concrete acceptance target.

Chord / double stop

An event must support multiple simultaneous notes instead of one pitch.

Explicit beam groups

Preserve beam level and begin / continue / end / hook relationships.

Displayed accidentals

Separate sounding pitch alteration from the symbol visibly printed on the page.

Per-note fingering

Attach finger numbers to the correct note inside a chord.

Event(
  duration = 3/16,
  notes = [
    Note(B4, fingering=4),
    Note(G4, fingering=2)
  ],
  beams = [Beam(1, "begin")]
)

Event(
  duration = 1/16,
  notes = [Note(E4)],
  beams = [
    Beam(1, "continue"),
    Beam(2, "forward_hook")
  ]
)
Sequencing rule: do not derail the current M8 recognition gate. Score IR v2 can be designed and round-trip tested in parallel, but model-training scope should stay on the current rhythm-clean V1 target until the project is producing credible exact systems.

Then expand

Rich notation after the foundation

Once the first four relationships round-trip correctly, add richer expressive and polyphonic notation incrementally.

05

Slurs

Relationship across different pitches; distinguish from ties using pitch/context.

06

Articulations

Staccato, accent, tenuto, fermata.

07

String technique

Up-bow, down-bow, pizzicato, arco, harmonics.

08+

Tuplets, dynamics, voices

Add irregular rhythm, expression, and multi-voice structure after core event relationships are stable.
